# Offline Python parity references

`model_catalog_copy.py` and `model_probe.py` preserve the pre-TypeScript diagnostic implementation for optional development tests only. Production diagnostic modules do not import or invoke them.

`model-golden.json` is generated from that unchanged catalog copy by `generate_model_golden.py`. All inputs are synthetic; generation does not read configuration or contact any provider. It covers UTC, Asia/Tokyo, and America/New_York local-calendar behavior, including a daylight-saving transition in the 240-day window.

Run the normal parity checks with Node only:

    node --test backend_diag/tests/model-parity.test.mjs

To deliberately refresh reference outputs on a Python environment with `time.tzset` and timezone data:

    python backend_diag/tests/reference/generate_model_golden.py

Inspect fixture changes before accepting them. The expectations must remain generated by the original reference, not the TypeScript implementation under test.
