## 1. メニューと一覧の共通操作

### 操作の流れ

1. 上部メニューから目的の区分を選びます。Mマスタは基本情報、Tトランは日々の伝票、Vビューは集計、Sスケジュールは日・週の予定です。
2. 機能を開き、検索条件を指定して対象行を探します。
3. 対象のIDと名称を確認して編集画面へ進みます。変更後は保存し、一覧から再度開いて値を確認します。

入力を取り消す場合は保存せずに戻ります。削除の確認が出たときも、対象IDを見てから確定します。

## 2. マスタを用意する

### 操作の流れ

1. 区分・分類・工程など、選択先になる基本情報を先に登録します。
2. 取引先・車両・商品を登録し、一覧でIDを控えます。
3. 商品構成では完成品を選び、材料と必要数量を明細へ入力して保存します。

成功の目印は、再表示した値が入力どおりで、次の伝票画面の選択欄から利用できることです。

### セルフテスト項目（未実施）

`/Mマスタ/<機能名>/一覧` から新規登録し、保存後に検索・再表示・変更を行います。各対象で登録・読取・更新・削除を確認します。後続で参照するレコードの削除は7章で行います。

| ID | 対象と操作 | 期待結果 |
|---|---|---|
| WB-201 | M配車区分、M生産区分、M生産工程を試験名で登録します。 | 各選択欄に使え、更新・検索結果が一致します。 |
| WB-202 | M商品分類、M取引先分類、M取引先、M車両を登録します。 | 分類と関連先を正しく選択でき、未選択・取消で意図せず値が変わりません。 |
| WB-203 | 完成品Aと材料BをM商品へ登録します。 | 商品コード・分類・単位等が再表示でも保持されます。 |

各マスタの主キー・必須項目は現行の編集画面に従います。表示名から型を推測せず、採番されたIDを本書の記録表へ記録します。重複IDの試験には試験用レコードだけを使います。

## 3. 配車を登録する

### 操作の流れ

1. 「Tトラン」から「T配車」の一覧を開き、新規登録へ進みます。
2. 配車日・区分・車両・取引先など画面の必須項目を入力し、対象を確認して保存します。
3. 一覧で登録したIDを探し、日付と名称を確認します。予定の見え方は6章のスケジュールでも確認できます。

## 4. 生産と払出を確認する

### 操作の流れ

1. 「T生産」の一覧から新規登録へ進み、完成品・生産数量・工程・日付を入力します。
2. 材料明細の品目と数量を確認して保存します。構成からの必要量と、保存された明細の数量を照合します。
3. 「T生産払出」の一覧で同じ生産を検索し、払出の参照内容を確認します。

生産数量を変更した場合は、材料数量も意図どおりか再表示して確認します。

| ID | 操作 | 期待結果 |

## 5. 入庫・出庫・棚卸と推移

### 操作の流れ

1. 「T商品入庫」で商品・日付・入庫数量を入力し、保存します。
2. 「T商品出庫」で同じ商品・対象日・出庫数量を入力して保存します。
3. 「T商品棚卸」では棚卸日を入力し、明細の商品ごとに「実棚数量」を入力します。ここには差分ではなく、実際に数えた数量を入れます。
4. 「V商品推移表」で同じ商品と対象期間を指定し、入庫・出庫・棚卸後の数量を確認します。

例では初期0→入庫10→出庫3で7、実棚数量8の棚卸後は8が期待値です。これは説明用の期待値で、実測結果ではありません。

### セルフテスト項目（未実施）

ほかの試験の影響を避けるため、在庫用の新しい試験商品Cを作ります。初期在庫と対象期間を確認してから進めます。

| ID | 操作 | 期待結果 |
|---|---|---|
| WB-501 | T商品入庫で商品Cを10個登録します。 | 一覧と再表示で数量10を確認できます。推移上の増分も10です。 |
| WB-502 | T商品出庫で同じ商品を3個登録します。 | 増減の符号と残数が一致します。初期0なら残数7です。 |
| WB-503 | T商品棚卸の明細で「実棚数量」に8を入力して登録します。 | 棚卸後の残数が8です。「実棚数量」は差分ではないため、差の＋1を入力しません。 |

| WB-505 | 入出庫と棚卸の試験行を1件ずつ変更・削除して再確認します。 | 一覧・明細・推移へ反映されます。各段階の期待残数を先に計算し、実値と照合します。 |

2. 車両または工程で対象を探し、予定の日時と内容を確認します。
3. 日表示でも同じ対象を開き、元の伝票と一致することを確認します。

## 7. データの整理と整合性

### 操作の流れ

試験を行った場合だけ、記録したIDで対象を確認し、伝票→商品構成→商品などの関連マスタの順に削除します。通常業務のデータを、この確認手順のために削除しないでください。削除後は一覧・集計・スケジュールを再表示し、対象だけが消えたことを確認します。

### セルフテスト項目（未実施）

試験データ本書の記録表を見て、参照する側から片づけます。DBファイル全体の置換は行いません。

|---|---|---|
| WB-701 | 試験のT配車、T生産と明細、入庫・出庫・棚卸を削除します。 | 試験対象だけが消え、一覧・払出・集計・スケジュールに残りません。 |
| WB-702 | 商品構成の後、試験商品・車両・取引先・分類・区分・工程を参照順に削除します。 | 参照制約がある場合は案内が出ます。解除後に削除でき、既存データは保たれます。 |
