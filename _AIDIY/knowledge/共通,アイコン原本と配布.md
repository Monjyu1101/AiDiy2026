# AiDiy アイコンの原本と配布

## 原本は所有モジュール、配布はローカルコピー

各アプリの編集元は所有モジュール内の SVG / PNG 一組だけです。Diag は PNG コピーを使い、他 module の素材を実行時・通常 build / setup / verify / test から参照しません。外部原本を必須にする共通 registry も設けません。

| 対象 | SVG / PNG 正本 |
|---|---|
| Console / Code / Live / IDE / Task / Team / Browser | `frontend_ide/aidiy_<名前>/AiDiy_<名前>.{svg,png}` |
| Avatar | `frontend_avatar/public/icons/AiDiy_avatar.{svg,png}` |
| Diag | `backend_diag/icons/AiDiy_diag.{svg,png}` |
| Hermes | `command_hermes/assets/AiDiy_hermes.{svg,png}` |
| Discord / Slack | `frontend_channels/<名前>/panel/AiDiy_<名前>.{svg,png}` |

`frontend_ide/public/`、Diag の `ui/src/アプリ起動/アイコン/` と `static/`、現行 Discord の `frontend_channels/panel/AiDiy_discord.png` は配布コピーです。Hermes の Diag コピーは `CLIアイコン/aidiy_hermes.png` / `static/CLI_aidiy_hermes.png` です。コピーを編集元にしません。

共通人物原画 `_icons/AiDiy.png` は PNG のみが正本です。存在しない SVG をトレースして新作しません。各アプリの共通人物 PNG は自己完結した配布に必要なコピーです。Browser 実窓のタスクバーは従来の名称帯なし原画を維持し、Diag の名称帯付き Browser とは用途を区別します。

Chrome / VS Code / 外部 CLI はこの整理の対象外です。従来の SVG、原素材、ライセンス表示を保持します。既存 AiDiy 各アイコンの固有色や絵柄も変更しません。

## 更新・配布手順

1. 所有モジュールの SVG を編集し、必要な場合だけ PNG を書き出します。単なる移動では既存 PNG を再描画しません。SVG のテキストは OS フォント差で字形が変わるためです。素材は自己完結させ、ネットワーク参照を追加しません。
2. 正本更新時だけ、保守担当が必要な配布先へ PNG を明示的にコピーして SHA-256 を照合します。通常 build や起動のたびに他 module から自動コピーする方式は禁止します。画像生成専用スクリプトは常設しません。
3. 各 module 内のコピーが揃ってから、その module の配布ビルドを実行します。

```bash
npm --prefix frontend_ide run build
npm --prefix frontend_channels run build:panel
npm --prefix backend_diag/ui run build
node backend_diag/ui/verify.mjs
```

IDE の build は同じ `frontend_ide` 内の正本 PNG を `public/` / `dist/` へコピーします。現行 Discord も同じ `frontend_channels` 内だけで完結します。将来 Discord / Slack の runtime を別 module に移す際は各 module 内へ閉じた構成を引き継ぎます。

Diag は自分の `ui/src/` の PNG / CSS と `icons/` だけを使います。`ui/src/共通表示/` と Discord の `panel/titlebar.css` は配色のローカルコピーです。共通配色変更時に保守担当が byte 同一のコピーを更新しますが、通常 build / verify に `frontend_ide` は不要です。共有 runtime JS/TS の既存連携を廃止する変更ではありません。

## Discord / Slack の名称帯

人物は共通原画のまま、下128pxは黒い帯・白いアウトライン文字です。8pxの白枠はこの帯だけに置き、人物領域を囲みません。SVG の元画像は無改変 PNG の data URI、文字はパスで保持します。Diag は完成 PNG のみを配布します。Slack 素材の追加は Slack 起動機能や接続の実装を意味しません。

## 回帰確認

```bash
node --test backend_diag/checks/aidiy-icon-ownership.check.mjs backend_diag/checks/channel-icons.check.mjs
node --test frontend_ide/checks/console-icon-title.test.mjs frontend_ide/checks/task-team-icons.test.mjs
```

module 内の PNG 一致、不要 SVG 配布の不在、固定 asset allowlist、通常・ミニ・マイクロの Hermes PNG 参照を確認します。ハンドラは mock request/response で検証し、実待受や GUI を必要としません。兄弟 module の画像・CSSが無い隔離 fixture で build / verify も実施します。所有者間の byte 一致はこの通常回帰とは別の保守検査にし、実 OS の表示検証と混同しません。
