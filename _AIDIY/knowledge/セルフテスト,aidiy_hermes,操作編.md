# Hermes 操作編 — 操作ガイドとセルフテスト

本書はHermes 操作編の操作・確認結果をまとめます。記載した実機・隔離試験・未確認の条件を区別します。PDFは本文とエビデンスの確定後に作成します。

## 1. 起動

`aidiy_hermes` またはDiagから起動します。選択プロジェクトのConsoleでMCP初期化が完了し、Hermesの入力待ちになることを確認します。Diagの通常表示とランチャー表示から入力待ちを確認しています。

ミニランチャーの「HERMES」で開いた窓は「AiDiy Console / Hermes」です。上部のプロジェクト名と接続済み、右下のToolsオンラインを確認したあと、端末本文の「Welcome to AiDiy Hermes!」と「Ask anything, or type / for commands...」の入力待ち案内まで確認します。接続直後に本文が空でも、接続表示だけでCLIの準備完了や失敗を判定しません。2026-11-01の実演では、空の本文から初期化案内と入力待ちへ変わることを確認しました。会話・コマンドの送信はしていません。

## 2. 会話・モデル・コマンド

本冊子の会話・モデル切替・スラッシュコマンドの操作結果は未記載です。起動画面の確認を、これらの動作確認の成功とは扱いません。

## 3. 終了

Consoleの窓を閉じ、所有サーバーと待受ポートが終了することを確認しました。他のCLIの窓は継続しています。端末共通の操作は[Console操作編](./セルフテスト,aidiy_console,操作編.md)を参照します。

単独窓の終了はタイトル右上の「×」を使い、窓一覧から消えたことを確認します。今回の実演ではAlt+F4が窓を閉じず、端末入力に制御キー由来と思われる文字が現れました。送信せず「×」で終了しました。端末がキーを取り込む場合は、ショートカットを繰り返さず通常の閉じるボタンを使います。
