## 変更内容

### Navigator（`aidiy_navi`）の新設

- 目標・作業項目・推定達成率・次のプロンプトを表示する読み取り専用の開発案内。提案は自動実行せず、既存 CLI の読み取り専用境界を使う。IDE の「＋ Navigator」と単独起動（`aidiy_navi.cmd`、`_setup.py` / `_start.py` / `_cleanup.py`）の両方から開ける。
- 記録形式は `schemaVersion: 3`。項目の工数比率は合計 100%、総合達成度は重み付き平均と一致させ、`nextItemId` は上から最初の未完了項目に一致させる。旧形式への自動切替は行わず、「＋ 新規」で記録を切り替える。
- Diag にアイコン（`AiDiy_navi.png`）、円周配置、ランチャー表示、`navi_info.mjs`（Navi 用モデル情報）を追加。
- 11/04 の後続コミットで、AI 重み付き評価と根拠、評価の固定表示・数値達成度・理由の折りたたみ、応答 JSON の抽出、未完了項目へのプロンプト生成、コピーの代替経路、Code / Live への引き渡し、入力欄・ボタン・通知のレイアウトを整備。
- `e59178e` で対応 AI を `aidiy_hermes` / `codex_cli` / `copilot_cli` / `claude_cli` / `grok_cli` へ拡大（`backend_diag/モデル情報/navi_providers.mjs` に一覧を集約）。Claude / Grok は読み取りツールだけを公開し、MCP・サブエージェント・セッション継続を無効化する引数で起動し、古い CLI が受け付けない場合は通常実行へ戻さず失敗する。Windows の Codex は `features.prefer_mxc=true` を指定。コマンド有無の確認はタイムアウト・未導入・確認失敗を区別して表示し、画面表示時には環境を再確認せず Diag が保存した候補を使う。
