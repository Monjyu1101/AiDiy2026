## 3. VS Code拡張で使う

VS Codeでは、先にプロジェクトフォルダを開きます。未選択時は入力欄のすぐ上に赤字で「先にプロジェクトフォルダを開いてください」と表示され、入力・送信・接続・モデル操作を無効にします。「フォルダを開く」から実在するローカルフォルダを選ぶと、案内が消え、通常の認証・接続条件を再評価します。単一ファイルを開くだけでは対象フォルダの選択になりません。フォルダを閉じると再び操作を抑止し、切替時は古い接続を引き継ぎません。 フォルダを開いた直後は拡張の再読込を待ち、赤字が消えたことと上部のプロジェクト名の両方を確認します。空の描画途中の画面を準備完了とは扱いません。単独Electron版の起動方法は変わりません。
