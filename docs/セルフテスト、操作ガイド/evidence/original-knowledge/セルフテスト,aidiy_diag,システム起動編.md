**✅ OK（記載した確認範囲）。** Windowsの実Diagで5つの操作を確認しました。画面の表示だけでなく、対象サービスの起動・停止とWebのログイン画面を照合しています。

## 始める前に

セットアップ済みの環境で `aidiy_diag` を起動し、「システム起動」を開きます。ミニ表示で開いた場合は「元のサイズに戻す」で通常画面へ戻します。アイコン表示・ミニ表示・ランチャー画面は[ランチャー編](./セルフテスト,aidiy_diag,ランチャー編.md)で扱います。

各機能名を押すと、その機能の設定とログが表示されます。「起動対象」は一括起動に含める指定です。「自動再起動」はプロセスが終了したときに起動し直す指定で、手動の停止操作では停止を維持します。

## 1. 一括起動する

1. 機能名を順に押し、まとめて起動する機能の「起動対象」をONにします。通常はTools / MCP・Core・Apps・Task / Team・WebをON、LocalをOFFにします。
2. 全機能が停止していることを確認し、右上の「一括起動」を1回押します。
3. 上部の進捗を見ながら待ちます。Tools → Core → Apps → Task / Team → Webの順に起動します。
4. 選んだ5機能が緑になれば起動完了です。Web画面の自動表示は4章で説明します。

起動前の画面です。6機能が灰色で、右上に「一括起動」が表示されています。Diagを開いただけではサービスは起動しません。

起動には時間がかかるため、処理中はボタンを連打せずに待ちます。

## 2. 強制停止する

1. システムを使うアプリで作業を保存し、利用を終了します。
2. 「システム起動」の右上にある「強制停止」を1回押します。
3. 進捗表示が消えるまで待ちます。Web → Task / Team → Apps → Core → Tools / MCP → Localの逆順で停止します。
4. 全機能が灰色になり、右上が「一括起動」に戻ったことを確認します。

停止途中の画面です。Web・Task / Team・Appsが停止し、Coreの停止処理が進んでいます。

## 3. 個別に起動・停止する

### 個別起動

1. 起動したい機能名を押します。
2. コンソール右側の「再起動」を押します。停止中の機能を起動する場合も、このボタンを使います。
3. 対象が緑になり、「稼働中」と表示されるまで待ちます。

Localを個別起動した画面です。「起動対象」はOFFでも個別に起動できます。「起動対象」をONにしない限り、次の一括起動には含まれません。

### 個別停止

1. 停止したい機能名を押します。
2. コンソール右側の「停止（Ctrl+C）」を押します。

Appsだけを停止した画面です。Appsは赤い表示になり、他の5機能は緑のままです。「自動再起動」がONでも、手動で停止した機能は停止を維持します。

**完了の目印：** 起動は緑・「稼働中」、個別停止は「停止済み」で判断します。他の機能の状態も合わせて確認します。

## 4. チェックを付けてWeb画面を開く

4. Webの起動後、ブラウザにAiDiyのログイン画面が表示されるまで待ちます。

Webの設定と起動完了の画面です。「ブラウザで開く」にチェックがあり、コンソールには安定確認とWebを開いた結果が表示されています。

### 5サーバー停止・復旧の実機再確認（2026-11-02 UTC）
