## 2. 会話・モデル・コマンド

使える操作を調べるには、端末の入力待ちで `/help` を入力してEnterを押します。カテゴリ別のコマンド一覧と説明が表示されます。長い一覧から目的の操作を探すときは、`/help model` のように半角スペースの後ろへ検索語を添えます。コマンド名や説明に関連する項目へ絞られ、末尾に `Filtered by 'model'` と表示されます。全一覧へ戻すには `/help` を使います。

`/help model` は説明の絞り込みで、モデルを変更する `/model` の実行とは異なります。表示されたコマンドを実行する前に、その説明と変更・送信の有無を確認します。2026-11-02の実演では、実際の入力操作による全一覧と `model` の絞り込みを確認しました。会話のAI送信・モデル切替は実施しておらず、それらの成功とは扱いません。

現在の状態を確認するには、入力待ちで `/status` を入力してEnterを押します。`Hermes CLI Status` の `Model` はモデルと接続方式、`Tokens` はセッションの使用量、`Agent Running` はAI処理中かどうかです。`Session ID` は会話の識別子で、認証キーではありません。`Path` はHermesの保存場所で、上部の選択プロジェクトとは区別します。設定変更やAIへの依頼は行わない読み取りコマンドです。

2026-11-02の新規セッションで1回実行し、`Model: gpt-6.1-sol (openai-codex)`、`Tokens: 0`、`Agent Running: No`、入力待ちへの復帰を実画面で確認しました。Context等は状態により省略されるため、必ず出ると説明しません。録画前には出力実装を確認し、以前の会話タイトルや個人パスが含まれるセッションをそのまま表示しないようにします。

## 3. 終了

単体CLIでは入力待ちで `/quit` を入力し、起動元のコマンドプロンプトへ戻ったことを確認します。`--delete` は履歴削除を伴うため通常終了の確認には付けません。

Consoleの窓を閉じ、所有サーバーと待受ポートが終了することを確認しました。他のCLIの窓は継続しています。端末共通の操作は[Console操作編](./セルフテスト,aidiy_console,操作編.md)を参照します。

単独窓の終了はタイトル右上の「×」を使い、窓一覧から消えたことを確認します。今回の実演ではAlt+F4が窓を閉じず、端末入力に制御キー由来と思われる文字が現れました。送信せず「×」で終了しました。端末がキーを取り込む場合は、ショートカットを繰り返さず通常の閉じるボタンを使います。
