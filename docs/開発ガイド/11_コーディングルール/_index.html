日本語と英語の使い分け

AiDiyでは業務ドメインを日本語、フレームワークや一般的な制御語を英語で表します。

日本語を使うもの

  • テーブル名: C利用者, M商品, T配車
  • カラム名: 利用者ID, 商品名
  • API endpoint: /core/C利用者/一覧
  • JSON keys: 利用者名, 商品ID
  • Vue component: C利用者一覧.vue

英語を使うもの

  • フレームワーク用語: router, store
  • 一般的な通信語: request, response, query
  • 統一レスポンス: items, total, limit
  • Vue API: ref, computed
