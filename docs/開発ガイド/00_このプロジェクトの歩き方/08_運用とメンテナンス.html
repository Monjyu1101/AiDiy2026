08. 運用とメンテナンス

運用の概要

このシステムの運用に必要な基本的な知識をまとめています。
開発環境での日常的な運用作業について説明します。

データベース管理

SQLiteデータベースの管理方法について説明します。

リセット手順

データベースを初期状態に戻す手順です。

# 1. サーバーを停止 (Ctrl+C 推奨)

# 2. データベースファイルを削除
del workspace/AiDiy2026/_data\AiDiy\database.db

# 3. サーバーを再起動してDBを再作成
cd workspace/AiDiy2026
python _start.py
注意

SQLiteはファイルベースのデータベースです。
database.db を削除すると全データが失われます。

バックアップ場所

データベースファイル _data\AiDiy\database.db
バックアップ命名規則 日付付き: database_backup_20260214.db
復元方法 バックアップファイルを database.db にコピーして上書き
ポイント

database.db は定期的にバックアップを取ることを推奨します。
特に重要なデータ変更の前にはバックアップを取得してください。

ログ出力

サーバーのログを確認する方法です。

ログの出力方法

python _start.py のコンソール出力に加え、バックエンドのログは主に backend_server/temp/logs/ へ保存されます。

ヒント

ログをファイルに保存したい場合は、
リダイレクトを使用してください。 

python _start.py > server.log 2>&1

ログレベル

  • DEBUG — 詳細なデバッグ情報
  • INFO — 一般的な情報メッセージ
  • WARNING — 警告メッセージ
  • ERROR — エラーメッセージ
  • CRITICAL — 致命的なエラー

バックエンドのコード変更を反映する方法

_start.py で起動した場合、uvicorn の --reload フラグが付かないため、コード変更が自動で反映されません。

方法1: Reboot機構を使う（推奨） 
# core_main.py を再起動
echo. > backend_server/temp/reboot_core.txt

# apps_main.py を再起動
echo. > backend_server/temp/reboot_apps.txt

_start.py がファイルの作成を検知して対象サーバーだけを再起動します。

方法2: 個別起動で --reload を有効化 
cd backend_server
.venv\Scripts\python.exe -m uvicorn core_main:app --reload --host 0.0.0.0 --port 8091
方法3: _start.py を再起動

Ctrl+C で停止してから python _start.py を再実行します。

復旧手順

ステップ1: 初期アカウントの確認

ログインできない場合、初期アカウントを確認してください。

  • ユーザー名: admin
  • パスワード: ********

初期アカウントでもログインできない場合は、401レスポンス、JWT設定、C利用者 の有効状態とパスワードを確認します。DB全体のリセットを先に行わないでください。

ステップ2: データベースとスキーマ差分の確認

_data/AiDiy/database.db をバックアップし、Modelと実カラム、core_crud/init.py / apps_crud/init.py の起動時差分処理を確認してから再起動します。DB削除はデータ破棄が許可された開発環境の最終手段です。

ステップ3: ポート競合の解消
# 1. サーバーを停止する

# 2. 起動対象ポートの使用状況を確認（例）
netstat -ano | findstr :8090
netstat -ano | findstr :8091
netstat -ano | findstr :8093
netstat -ano | findstr :8095
netstat -ano | findstr :8098

# 3. プロセスを強制終了
taskkill /F /IM python.exe
taskkill /F /IM node.exe
補足

_stop.py は現行リポジトリにありません。必要に応じて taskkill またはポート単位の停止で対応してください。

ステップ4: 依存パッケージの再インストール
# バックエンドの依存パッケージを再インストール
cd workspace/AiDiy2026/backend_server
uv sync

cd workspace/AiDiy2026/frontend_web
npm install

クリーンアップ

不要なファイルを削除してプロジェクトを整理します。

cd workspace/AiDiy2026
 python _cleanup.py

このスクリプトは対話形式で対象を最初にまとめて選択し、常駐サービスを停止してからクリーンアップします。

主な選択対象

対象説明デフォルト
グローバルAI CLInpm系AI CLIツールのアンインストールn
backend_local仮想環境とtemp（ダウンロード済みモデルを含む）対象選択 y
backend_tools仮想環境、node_modules、temp、MCP設定解除対象選択 y
backend_server仮想環境、temp、SQLite DB対象選択 y / DB削除はn
backend_taskteam仮想環境とtemp対象選択 y

フロントエンド関連

対象説明デフォルト
frontend_webnode_modules、dist、キャッシュ等はサブプロジェクトのcleanupへ委譲対象選択 y
frontend_avatarnode_modules、dist、Electron成果物等はサブプロジェクトのcleanupへ委譲対象選択 y

その他

対象説明デフォルト

Tip

SQLite DB、backup、ダウンロード済みモデルを消す選択は復旧不能になり得ます。選択内容を確認してから実行してください。
仮想環境やnode_modulesを削除した後は python _setup.py で再セットアップします。

バックアップ

データを安全に保管するためのバックアップ方法です。

SQLiteバックアップ

SQLiteはファイルコピーでバックアップできます。

# バックアップの作成
copy workspace/AiDiy2026/_data\AiDiy\database.db workspace/AiDiy2026/backup\database_20260214.db

# バックアップからの復元
copy workspace/AiDiy2026/backup\database_20260214.db workspace/AiDiy2026/_data\AiDiy\database.db
バックアップのポイント
  • 定期的にバックアップを取得してください
  • 重要な変更の前にはバックアップを作成してください
  • バックアップファイルは別フォルダ/別ドライブに保存してください
注意

Windowsではサーバー停止中にコピーしてください。
Windowsのタスクスケジューラで自動バックアップも設定できます。
