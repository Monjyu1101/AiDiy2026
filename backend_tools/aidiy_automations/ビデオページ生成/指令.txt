【目的】
最新のAIニュースを1件選び、解説動画のHTMLページを作って、Xビデオメニューから再生できるようにする。

【題材の条件】
- 機能追加・性能向上など、初心者でも楽しめるニュースであること
- 中国系の企業・製品・研究は除外する
- 調査には grok_cli を使う
- 既に作成済みのテーマは選ばない

【手順】
1. grok_cli で最新のAIニュースを調査し、上記条件に合う候補を3件挙げる。
2. "frontend_web\public\Xビデオ\ニュース_*" のフォルダ名を一覧し、
   既存テーマと重複しない候補を1件に絞り込んで題材を確定する。
3. 確定した題材を
   "backend_tools\aidiy_automations\ビデオページ生成\_ビデオページ生成_解説_設定.json"
   の topic と folder_name へ書き込む。folder_name は ニュース_YYYYMMDD_<テーマ>_ja 形式にする。
   ※ 以降の全ステップは、この設定JSONの内容だけを見て進めること。
     手順2で選んだ題材と成果物が食い違うと、最終確認で不合格になる。
4. "backend_tools\aidiy_automations\ビデオページ生成\ビデオページ生成_解説.py"
   をステップ番号を指定して1ステップずつ実行する。
   実行コマンド: cd backend_tools && .venv\Scripts\python aidiy_automations\ビデオページ生成\ビデオページ生成_解説.py <ステップ番号>
   ステップ番号は 0=初期確認 1=フォルダ作成 2=ルーティング追加 3=シナリオ作成 4=HTML修正
                  5=画像生成 6=中間確認 7=音声生成 8=再生時間更新 9=最終確認 99=完成案内
   1つのステップを1つの明細にする（複数ステップをまとめて実行しない）。
   ※ ステップ2で "frontend_web\src\components\Xビデオ.vue" のメニューカードと
     "frontend_web\src\router\index.ts" のルーティングが自動登録される。
     ここが成功してからブラウザ表示が始まるので、手動でメニューへ追加しないこと。
5. frontend_web で npm run type-check が通ることを確認する。

【完了条件】
- 出力フォルダに index.html / scenario.js / images / audio が揃っている
- 画像と音声が scenario.js の参照と一致し、欠落がない
- Xビデオ.vue のメニューから開けて、音声つきでループ再生される
- 手順2で選んだ題材と、設定JSON・成果物・メニューの表記がすべて一致している

【注意】
- ステップ数が増えても構わない。1明細＝1処理になるよう細かく分けてよい。
- 各ステップは前のステップの成果物を前提にする。順番を飛ばさない。
