# Xピンボールsol_new 進化盤面仕様

この文書は `game.js` の進化記憶・進化レールを改修するときの基準である。座標は Canvas の `720 x 1080` を基準とする。

## 目的

- 成功軌跡は、再び盤面上部へボールを運ぶ「成功レール」として強化する。
- 失敗軌跡は、次の落球を一度だけ救う「救済レール」と、落球方向から押し戻す「危険回避場」として残す。
- 進化要素は通常の壁・フリッパー・発射機構を置き換えず、追加の補助物理として働く。
- 同種レールは成功用1本、救済用1本を上限とし、軌跡の重複による閉塞を防ぐ。

## 記憶と世代

| 項目 | 確定仕様 |
|---|---|
| 成功記憶の成立 | 盤面進入後、バンパー・ターゲット・ゲートは重み1、SOL COREは重み2、成功レールは重み1として、同一ボールの累計が2以上になった時点 |
| 失敗記憶の成立 | 盤面進入済みの各ボールが落球した時点。最終ライフおよびマルチボールも各球を個別に記憶する |
| 記憶件数 | 成功6件、失敗6件。超過時は最古から破棄する |
| 1記録の点数 | 最大18点。盤内の有効点が5点未満の軌跡は採用しない |
| 世代更新 | 成功または失敗の有効記憶を1件採用し、進化盤面の再構築が完了した時に1だけ増加する |
| 更新しない場合 | 無効軌跡、単なる再描画、ラウンド開始、レール接触だけでは世代を増やさない |
| リセット | 新規ゲーム開始時に記憶、世代、レール、救済回数をすべて初期化する |

成功経路は直近2件を旧35%・新65%で合成する。失敗経路も直近2件を同じ比率で合成する。各経路は進行方向を落球側から盤面上側へそろえ、隣接点間が短すぎる点を除去してからレール化する。

## 成功が強化する要素

成功記憶は `memoryKind: "success"` の成功レール1本へ反映する。

- 有効領域は `x=105..540`, `y=150..790` とする。
- 合成経路のうち5点以上が有効領域へ残る場合だけ生成する。
- ボールを上へ返す補助速度は `vy -= 145` とする。
- 反発係数は `clamp(1.00 + 成功記憶件数 * 0.02 - 失敗記憶件数 * 0.005, 1.02, 1.12)` とする。
- 寿命は生成から24秒とし、新しい成功レールが成立した時は古い成功レールを置換する。
- 生成後0.20秒は衝突判定を無効にし、生成中のボールを挟まない。

## 失敗が救済する要素

失敗記憶は `memoryKind: "rescue"` の救済レール1本と、最大4個の危険回避場へ反映する。

- 救済レールの有効領域は `x=105..540`, `y=610..790` とする。
- 失敗経路の下側を左右中央方向へ34px、上方向へ42〜74px移し、落球側から盤面上側へ向かう経路にする。
- ボールを上へ返す補助速度は `vy -= 115 + min(失敗記憶件数, 6) * 10` とする。
- 反発係数は `clamp(1.02 + 失敗記憶件数 * 0.012, 1.04, 1.10)` とする。
- 寿命は次ラウンド開始から30秒、または最初の有効な救済接触までの早い方とする。
- 新しい失敗記憶が成立した時は古い救済レールを置換する。
- 危険回避場は直近4失敗の終端付近に置き、半径54〜69px、強度0.80〜1.04とする。レールと同じ寿命で消える。

救済接触は、進入済みボールが救済レールへ向かって衝突し、衝突後の上向き速度が衝突前より増えた場合に限る。単なる重なりは救済回数に数えない。

## 閉塞禁止領域

次の領域には成功レール、救済レール、危険回避場の物理効果を置かない。線分が領域を横切る場合は境界で切り、5点未満になった断片は破棄する。

| 保護対象 | 禁止領域 |
|---|---|
| 発射レーン | `x=540..650`, `y=360..1040` |
| 盤面進入口 | `x=520..650`, `y=72..420` |
| フリッパー可動域 | `x=175..545`, `y=790..960` |
| ドレイン中央 | `x=280..440`, `y=930..1060` |

固定壁の内側から24px未満、バンパー・CORE・RIFT・PHOTON SAILの衝突半径内にも進化レールを置かない。これにより、通常の発射、盤面進入、左右フリッパーの全可動、中央落球口を常に残す。

## 得点条件

| 接触 | 得点 | 条件 |
|---|---:|---|
| 成功レール | `420 + min(有効接触回数, 10) * 35` | 同一ボール・同一レールは0.18秒の再得点待ちを置く |
| 救済レール | 160 | そのボールで最初の有効救済接触だけ |

得点には既存の倍率を適用する。生成直後の無効時間、静止した重なり、禁止領域内での接触には、得点・成功記憶・救済回数を付与しない。

## 完了判定

- 常に成功レール1本以下、救済レール1本以下、危険回避場4個以下である。
- 発射したボールが進化要素に妨げられず `entered: true` へ到達できる。
- 左右フリッパーの可動域と中央ドレインに進化レールが存在しない。
- 世代数は採用された成功記憶数と失敗記憶数の合計に一致する。
- レール消滅後は描画、衝突、得点、危険回避場のいずれにも効果が残らない。
