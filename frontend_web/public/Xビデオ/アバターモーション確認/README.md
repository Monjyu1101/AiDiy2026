# アバターモーション確認

`index.html` を Web サーバー経由で開く。`frontend_web` の Vite 開発サーバーなら `/Xビデオ/アバターモーション確認/index.html`。

- `00`: `frontend_avatar/public/vrma/標準/VRMA_01.vrma` を複製した現行モーション。
- `01`〜`20`: ポーズ名をファイル名に含む新規 VRMA。各ページで 1 ファイルを繰り返し再生する。
- `999`: 確認終了。モーション再生を止める。
- 「前へ」「次へ」、番号一覧、左右矢印キーで切り替える。音声は使用しない。
- 切り替え時は表示中のボーン姿勢を記録し、次の姿勢へ 1.1 秒かけて補間する。連続でページを送っても、その瞬間の姿勢からつなぐ。

候補の角度や揺れを変える場合は `vrma/generate.py` の `POSES` を編集し、同ファイルを Python で実行する。ファイル名やページの説明を変えたときは `motions.js` も合わせて更新する。

アバターには共通の `../_vrm/VRM_female.vrm` を使用する。Three.js と VRM ライブラリは既存の Xビデオと同様に CDN から読み込む。
