# Xアバター訓練中

`index.html` を Web サーバー経由で開く。`frontend_web` の Vite 開発サーバーなら `/Xアバター訓練中/index.html`。

- `00`: `frontend_avatar/public/vrma/標準/VRMA_01.vrma` を複製した現行モーション。
- `01`〜`20`: 少女アバターの待機中に使う仕草の候補。ポーズ名をファイル名に含む新規 VRMA。各ページで 8 秒のモーションを一回再生し、終了後は普通の立ち姿で止める。同じ番号を押すと再生し直せる。`18` のうなずきは一回。
- 左右対だった 7 組は片側のみ残す。残した番号は `01`、`04`、`06`、`09`、`13`、`14`、`19`。
- `02`、`03`、`07`、`08`、`12`、`15`、`18` はそれぞれ独立した仕草に差し替えた。`09` は左向きから腕を上げずに画面をのぞき込む。
- `999`: 確認終了。モーション再生を止め、普通の立ち姿に戻す。
- 「前へ」「次へ」、番号一覧、左右矢印キーで切り替える。音声は使用しない。
- 切り替え時は表示中のボーン姿勢を記録し、次の姿勢へ 1.1 秒かけて補間する。連続でページを送っても、その瞬間の姿勢からつなぐ。
- 頬・胸元・顎・お腹へ手を寄せる候補は、肩の向きと長軸回旋、肘の屈曲、前腕の回内外を分けて指定する。肘は左 +Y / 右 -Y の屈曲で150度以内、前腕の回内外は±60度以内。手首で掌を180度反転させない。
- 上腕の合成順序は Y → Z → X、前腕は Y → X → Z。全身用の XYZ 合成を腕の長軸回旋へ流用しない。
- 手首の揺れは±2度、前腕の揺れは肘の屈曲軸で±2度に留める。

候補の角度や動きを変える場合は `vrma/generate.py` の `POSES` と `bone_angles()` を編集し、同ファイルを Python で実行する。生成ファイルは VRMA 仕様の T ポーズ骨階層を持つ。ファイル名やページの説明を変えたときは `motions.js` も合わせて更新する。

アバターには共通の `../Xビデオ/_vrm/VRM_AiDiy.vrm` を使用する。これは `frontend_avatar/public/vrm/VRM_AiDiy.vrm` と同一のモデル。Three.js と VRM ライブラリは既存の Xビデオと同様に CDN から読み込む。

生成後の回帰チェックは `python vrma/test_generate.py`。生成データとコードの一致、肘・手首の可動域、上腕回旋で肘位置が変わらないこと、左右鏡映、フレーム間の連続性、中立への復帰を確認する。見た目はモデルと衣装によって変わるため、実モデルでも入口・保持中・出口を確認する。
