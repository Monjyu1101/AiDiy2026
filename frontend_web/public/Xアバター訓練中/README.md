# Xアバター訓練中

`index.html` を Web サーバー経由で開く。`frontend_web` の Vite 開発サーバーなら `/Xアバター訓練中/index.html`。

- `00`: `frontend_avatar/public/vrma/標準/VRMA_01.vrma` を複製した現行モーション。
- `01`〜`20`: 少女アバターの待機中に使う仕草の候補。ポーズ名をファイル名に含む新規 VRMA。各ページで 8 秒のモーションを一回再生し、終了後は普通の立ち姿で止める。同じ番号を押すと再生し直せる。`18` のうなずきは一回。
- 左右対だった 7 組は片側のみ残す。残した番号は `01`、`04`、`06`、`09`、`13`、`14`、`19`。
- `02`、`03`、`07`、`08`、`12`、`15`、`18` はそれぞれ独立した仕草に差し替えた。`09` は左向きから腕を上げずに画面をのぞき込む。
- `999`: 確認終了。モーション再生を止め、普通の立ち姿に戻す。
- 「前へ」「次へ」、番号一覧、左右矢印キーで切り替える。音声は使用しない。
- 切り替え時は表示中のボーン姿勢を記録し、次の姿勢へ 1.1 秒かけて補間する。連続でページを送っても、その瞬間の姿勢からつなぐ。
- 胸元・お腹へ手を寄せる候補は、肘と手首が胴体の前を通る角度にする。

候補の角度や動きを変える場合は `vrma/generate.py` の `POSES` と `bone_angles()` を編集し、同ファイルを Python で実行する。生成ファイルは VRMA 仕様の T ポーズ骨階層を持つ。08・13 の接地はページ側で実モデルの脚長に合わせて補正するため、VRMA 単体ではなく index.html と一緒に適用する。ファイル名やページの説明を変えたときは `motions.js` も合わせて更新する。

アバターには共通の `../Xビデオ/_vrm/VRM_AiDiy.vrm` を使用する。これは `frontend_avatar/public/vrm/VRM_AiDiy.vrm` と同一のモデル。Three.js と VRM ライブラリは既存の Xビデオと同様に CDN から読み込む。

## 腕・掌の調整

`vrma/generate.py` の `ARM_POSES` は右腕を基準にした
`(肩下げ, 肩前出し, 上腕ひねり, 肘屈曲, 前腕ひねり)` の角度です。
肩は Z→Y→X、肘屈曲は Y、前腕の回内外は X として別々に合成します。
肘を 150 度以内に保ち、左腕は Quaternion の `(x, -y, -z, w)` で鏡映します。
手首だけで掌の向きを無理に合わせず、前腕のひねりで胸・腹側へ向けます。
04/05/06は大きな袖口が胴体へ深く入るのを避けるため、手の意味・掌の向きを維持したまま腕の余裕を増やしています。衣装同士の接触を全て解消するものではありません。02は手を背中から少し離し、入口・出口で袖を腰の外側へ回す左右対称の経路にしています。02に関係する途中切替にも外向きの回避を加え、再度の割込にも引き継ぎます。中立姿勢にもともとある袖と腰の約3.9mmの接触は残ります。
01・06 は指先だけでなく、袖口が顔を隠さない位置を確認してください。
既定の立ち姿の肘は前方へ 10 度曲げ、生成器と `index.html` の idleAngles を一致させます。

切替補間では表示用の姿勢と Mixer の補間先を分けます。
同じ Quaternion を `slerpQuaternions` の出力と第2引数に使うと補間先が上書きされます。
また Mixer は一定値のトラックを毎フレーム書き直すとは限らないため、次の更新前に
補間前の姿勢を復元します。これにより、切替開始後の跳ねと前ページの膝の曲がり残りを防ぎます。描画を挟まない連続要求では、最初に保存した表示姿勢・足の位置を再利用し、Mixer停止で戻った値を表示姿勢と取り違えません。
読み込み失敗の Promise は、選択が別ページへ移った場合もキャッシュから除きます。

## 動作の意味と接地

- 左右は画面を見る人ではなく、アバター本人を基準にする。既定VRM_AiDiyはVRM1で、モデル空間の正面は+Z、本人の左は+X。ページではモデル全体をY軸で180度回して表示する
- 03は腰・脚を回さず、背骨と胸で右→左へ一往復する。15も上半身だけを左へ向ける
- 09は上体を左へ向け、背骨・胸の前傾で顔を画面へ近づける。カメラは動かさず、既定モデルの両眼中点が約26cm前進する。首・頭の縦方向の補正は前傾と同期し、腕は後ろへ浮かないよう下ろす
- 12は左足を一度だけ内側へ寄せて戻す。右足は支持脚として固定し、左足は中心線を越えない範囲にする
- 18のうなずきは一回で、小さな角度にとどめる。19は本人の左への首かしげ
- 呼吸は胸で表す。立ったままの仕草に腰の上下移動を加えない。腰を移動しない候補はtranslationトラックを省略して、モデル固有の中立位置を保つ
- 08のしゃがみと13の重心移動では、正規化された実モデルの脚長から二関節IKを解き、足首の位置と足の向きを維持する。届かない分だけ骨盤を下げ、膝は前へ曲げる
- 膝を完全に伸び切らせると余弦定理の平方根の境界で速度が急変するため、中立姿勢の脚長と小さな二次補間で補正開始を滑らかにする。中立姿勢の位置は変更しない
- 接地補正前のMixerサンプルは毎フレーム保存・復元する。切替開始時の足位置・向きも保存し、途中で別候補へ切り替えても跳ねないようにする
- 00の参考モーションは接地補正せず、そのまま再生する。12の左足だけは意図的に動かすため固定しない

この補正は訓練ページの直立した既定モデルを対象に確認したもの。任意のモデル体型、極端な姿勢、歩行、床の段差への一般的な接地機能ではない。

## 回帰確認

リポジトリのルートで実行します。

```sh
python frontend_web/public/Xアバター訓練中/vrma/generate.py
python frontend_web/public/Xアバター訓練中/vrma/test_generate.py
node frontend_web/public/Xアバター訓練中/tests/test_playback.mjs
node frontend_web/public/Xアバター訓練中/tests/test_intent.mjs
node frontend_web/public/Xアバター訓練中/tests/test_motion_continuity.mjs
node frontend_web/public/Xアバター訓練中/tests/test_motion02_interruptions.mjs
```

- Python は標準ライブラリのみ。全20候補、96,400個の回転、GLB構造、終端の中立姿勢、掌の方向、肘角度、左右鏡映、生成物の一致を検査します
- Node は `frontend_avatar` のインストール済み依存を使います。詳しい条件は `tests/README.md` を参照してください
- test_intent.mjsは全20候補のraw/normalized骨を60fpsで追跡し、足首・つま先の固定、胴体の左右、視線、膝、単発動作と75通りの切替を検査する
- Node は実際のページスクリプトと Three.js / VRM / AnimationMixer を実行しますが、DOM・描画・時計・ファイル取得を模擬するヘッドレステストです。ブラウザー描画の代わりにはなりません
- 見た目の確認では、01〜20を1候補ずつ、入口・保持・出口・停止を正面と斜めから確認します。02は背面、12は足を寄せる山、18は1回のうなずきも確認してください
- 実ブラウザーでは同じ番号の再生、読み込み中の連打、動作途中の999、08のしゃがみから14へ切り替えた後の膝の復帰を確認します

追加のtest_motion_continuity.mjsは、完了前の反転・再要求を24/30/60/120fpsと不規則間隔で検査し、240/600fpsで伸び切り付近の膝の速度・加速度が発散しないことを確認します。実ブラウザーや衣装の完全な非干渉を保証する検査ではありません。
