# アバター訓練ページのヘッドレス再生テスト

## 実行

前提は Node.js 18 以降と、`frontend_avatar` のインストール済み npm 依存関係です。
ページの importmap と同じ Three.js / `@pixiv/three-vrm` / `@pixiv/three-vrm-animation` のバージョンを使用します。
追加のランタイム依存関係やブラウザーは不要です。

リポジトリのルートから実行します。

```sh
node frontend_web/public/Xアバター訓練中/tests/test_playback.mjs
node frontend_web/public/Xアバター訓練中/tests/test_intent.mjs
node frontend_web/public/Xアバター訓練中/tests/test_motion_continuity.mjs
node frontend_web/public/Xアバター訓練中/tests/test_motion02_interruptions.mjs
```

別のインストール済み `node_modules` を使う場合は環境変数 `MOTION_QA_MODULES` にそのディレクトリを指定できます。
任意の `MOTION_QA_REPORT` に JSON レポートの保存先を指定できます。指定しなければファイルは生成せず、標準出力に結果を表示します。
レポートにはソース・モデル・VRMA の SHA-256、使用ライブラリのバージョン、各テスト結果と計測値が含まれます。

## 確認範囲

テストは `index.html` の実際のナビゲーションとモジュールスクリプトを読み込み、import 文だけを依存注入に置き換えて実行します。
再生処理をテスト用に複製していないため、ページの実装変更もそのまま検査対象になります。

- 01〜20 の VRMA を全て読み込み、1 回再生・終了イベント・中立姿勢への復帰を確認
- 00 の現行モーションを読み込み、1 回再生して復帰
- 全候補の 60fps の回転差分を測定し、5 度を超える急変を検出
- 同じ候補の連打、完了後の再選択、非同期ロードの順序逆転、失敗後の再試行
- 描画もstep(0)も挟まず5件を続けて要求する12ケースで、最初の表示姿勢と足の位置を維持
- 999 への移動、ロード中の中止、入口・出口の途中での再選択
- 01/02/04/05/06/10 の全組み合わせを 6 時点で切り替える 216 ケース
- 各切り替えの表示姿勢の連続性と、補間完了後の接地補正前のMixer姿勢が実際のクリップのサンプルに一致すること
- 08 のしゃがみ姿勢から 14 へ移るとき、一定値の脚トラックにも正しく戻ること
- 30fps・長いフレーム間隔、ボタン・番号・矢印・iframe メッセージのナビゲーション

## 動作意図・足の固定の回帰

`test_intent.mjs`は実ページを実行し、VRM更新後のraw骨（実際の描画骨）とnormalized骨を60fpsで追跡します。

- 01〜20の開始から中立への復帰までの全軌跡で、固定すべき足首・つま先の位置と回転を検査（12の左足だけ除外）
- 全raw骨の1フレームの移動・回転の急変と、終端で中立へ戻ることを確認
- 03の骨盤固定・胴体の左右の揺れ、08の膝と低下、09の両眼中点の前進24cm以上・顔の向き、09/15の左旋回、12の内向き、13の左重心、14の右視線、16/17の上下、18の一回の小さなうなずき、19の左傾き、20のおじぎ
- 00/08/09/12/13/999を開始途中・動作中・出口で組み合わせた108切替で、切替瞬間の連続性と補間後の接地を確認

位置の許容誤差は1mm、固定した足の回転は0.1度です。これは実モデルの骨の基準点・向きの誤差であり、靴底全頂点の床貫通や衣服の接触を測定した値ではありません。
`MOTION_QA_OUTPUT`を指定するとソースハッシュ付き結果と圧縮した全軌跡を書き出します。`MOTION_QA_REPORT`ではJSON結果だけを保存できます。
旧実装との検証用に`MOTION_QA_SOURCE`（index.html/motions.js）、`MOTION_QA_MOTION_ROOT`（VRMAとgenerate.py）の差し替えにも対応します。

## 完了前の連続切替・膝の速度

`test_motion_continuity.mjs`は24/30/60/120fpsおよび不規則なフレーム間隔で、8種類の要求列と3種類の決定的な乱数列を検査します。計55ケース・1,375要求で、表示姿勢・186点のスキニング頂点・接地目標・Mixerの未補正サンプルを毎フレーム比較します。
途中で再び戻す、同時刻に選び直す、12を繰り返す、00/08/12/13/999を行き来するといった流れが対象です。
さらに2種類の08→13切替を240/600fpsで実行し、膝が完全に伸びて速度や加速度が発散する旧挙動を検出する6件の回帰を実行します。計61検査です。閾値はこの再現ケース向けで、自然な動き全般を自動判定するものではありません。
出力は既定で標準出力のみです。`MOTION_QA_REPORT`で結果、`MOTION_QA_OUTPUT`で圧縮軌跡も保存できます。

## 02の袖と途中切替

`test_motion02_interruptions.mjs`は02→終了、02→05、05→02、再選択・反転・描画前の連続要求を計27系列で検査します。実モデルの袖と胴体・衣装・骨盤・太腿の三角形を使い、中立姿勢にもともとある接触と、新たに深く入る箇所を区別します。Nodeと既存依存関係だけで動きます。詳しい形状選択、許容値、限界は[README_motion02.md](./README_motion02.md)を参照してください。

## 限界

これは Node.js によるヘッドレスのロジック検証です。ブラウザー UI や見た目の自然さの確認ではありません。
Three.js の GLTFLoader、VRM/VRMA プラグイン、AnimationMixer、モデルのジオメトリと VRM 更新は実物を使います。
DOM、WebGLRenderer、時計、requestAnimationFrame、ファイル転送はテスト用に置き換えています。
テクスチャ読み込みは意図的に省いているため、その警告は想定内です。

描画結果、掌の見え方、陰影、テクスチャ、CDN/CORS、HTTP 配信、実ブラウザーのフォーカスや操作感は別途確認が必要です。
